# FastConnect .NET SDK Samples

## Chay

```bash
cd dotnet

# Chay sample cu the
dotnet run -- 01    # Auth
dotnet run -- 02    # Request & Verify OTP
dotnet run -- 03    # Index List
dotnet run -- 04    # OHLC
dotnet run -- 05    # Securities
dotnet run -- 06    # Balance
dotnet run -- 07    # Limit Order
dotnet run -- 08    # Market Order
dotnet run -- 09    # Order Status
dotnet run -- 10    # Cancel Order
dotnet run -- 11    # WebSocket Data
dotnet run -- 12    # WebSocket Trading
dotnet run -- 13    # MA Cross Auto Trade
dotnet run -- 14    # Lệnh điều kiện FCO
```

## Danh sach sample

| # | File | Mo ta |
|---|------|-------|
| 01 | Sample01Auth.cs | Xac thuc, lay token, kiem tra tai khoan |
| 02 | Sample02Otp.cs | Yeu cau & Xac thuc OTP (Push Smart OTP Polling) |
| 03 | Sample03IndexList.cs | Lay danh sach chi so thi truong |
| 04 | Sample04Ohlc.cs | Lay du lieu K-line (OHLC) nhieu timeframe |
| 05 | Sample05Securities.cs | Lay danh sach co phieu theo san/index & Master Data |
| 06 | Sample06Balance.cs | So du tai khoan, suc mua, vi the |
| 07 | Sample07LimitOrder.cs | Dat lenh Limit (LO) mua/ban |
| 08 | Sample08MarketOrder.cs | Dat lenh Market (MP) |
| 09 | Sample09OrderStatus.cs | Theo doi trang thai lenh (polling) |
| 10 | Sample10CancelOrder.cs | Huy lenh dang mo |
| 11 | Sample11WebsocketData.cs | WebSocket du lieu thi truong real-time |
| 12 | Sample12WebsocketTrading.cs | WebSocket trang thai lenh real-time |
| 13 | Sample13MaCrossAutoTrade.cs | MA Cross + WebSocket auto trade |
| 14 | Sample14FcoOrder.cs | Dat & quan ly lenh dieu kien FCO (GTD, Stop, Trailing Stop, OCO, Bull Bear) |
